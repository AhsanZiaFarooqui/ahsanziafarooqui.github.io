# Question bank and mathematical content

Source: `src/bank.ts`. Generated reference: `item-bank.json` and `item-index.md`; regenerate with `npm run bank:docs`.

There are **45 instances per module**: 25 authored diagnostic items and 20 parameterised practice/check/revisit instances. The latter are five task families, each with one guided, two independent and one reserved revisit instance. They are not claimed to be twenty different concepts. Fourteen separate tutorials contain checked examples.

Each instance includes ID, module, required skills, concept/misconception tags, prompt, visual, choice format, stable correct-answer ID, distractor meanings, slip/guess assumptions, difficulty, variant-family ID, eligible phase(s), accessible description and a hint. Distractor text is deduplicated before guess probability is computed. Shuffling changes only display order; scoring uses stable IDs, never option indices. The bank is hand-authored or generated from explicit authored templates, never generated by the AI at runtime.

Time covers hand roles, minute groups, the current hour between numerals, o’clock/half/quarter language, and combined five-minute readings. Fraction items mix symbolic and visual tasks on equal parts, symbol roles, shaded quantities, equivalence and comparison. All comparison strips have the same 480-unit rendered width. Internal units are 4, 8 or 12, with larger outlined groups distinct from stud cells.

At 3:30, “6:15” is only a possible hand reversal. The app follows with focused hand/minute items. A 3:3 response at 3:15 prompts minute-position evidence. A 4/3 response for three shaded quarters prompts separate total and selected counts. A 1/4 > 1/2 response prompts visual equal-whole comparison before interpretation. The options are clues; a single chosen distractor is not a diagnosed misconception.

Diagnostic variant families represent the assessed task and instance. Focused probes can share a mathematical component with an integrated item, intentionally separating explanations for the same error; they receive no correctness feedback during diagnosis. Families exclude literal repeats, not every conceptual overlap. Independent items are phase-reserved and use new task instances; they cannot reuse a previously answered item ID. Tutorial examples are authored separately. Guided examples can deliberately resemble teaching demonstrations; their performance is not independent evidence.

One unequal-pieces visual partitions a whole into 1/2, 1/4 and 1/4. Only the half is shaded. Counting one of three unequal pieces does **not** make it one third. The corresponding lesson subdivides the half into two quarters without changing the highlighted length.

All visual labels and answer keys come from trusted state. Clock angles are `6m` and `30(h mod 12)+0.5m` clockwise from twelve. Negative and positive minute offsets wrap across twelve. Rational equivalence/comparison uses integer cross-products; subdivision requires the number of units to be divisible by the denominator. No AM/PM is inferred.

These items and provisional difficulty labels have not been calibrated with children. An adult subject reviewer should review the full index, accessible descriptions and distractor plausibility before a supervised trial.
