Giving everyone the same explanation can miss the particular thing each child finds confusing.” There are no invented classroom observations, testimonials, gains or user counts.

## Continuation plan to personalise

1. Student and adult reviewer inspect examples and choose which real difficulty to investigate first.
2. Complete device/browser verification, then conduct a few voluntary supervised visits using the blank trial guide.
3. Record actual confusion, usability feedback and independently answered questions. Keep guided work separate.
4. Let the student choose one revision, explain why, and test it again. Keep the before/after artifacts and acknowledge assistance.
5. Review live AI wording with an adult before demonstrating it. Keep built-in mode available.
6. Assign a responsible maintainer and a small review schedule: verify answer keys after edits, rerun tests, inspect live-provider failures and update outdated documentation. Keep scope to clocks/fractions until these are dependable.
7. Consider broader testing and calibrated item parameters only with appropriate expertise, permission and resources. Replication is currently supported by the dependency-free local start commands, source and tests, not demonstrated adoption.
