How the audit avoids misleading conclusions

The code checks key uniqueness before joining, validates directional missingness and impossible values, compares strata with the administrative frame, and separately flags unmatched records on each side of a merge.

It does not automatically delete duplicates, impute missing values, or infer intentional manipulation. Those decisions require a prespecified protocol and context.

Suggested next production-grade checks

Evaluate weighted survey-response differences by sampling stratum, duplicate-household confirmation, interviewer effects, coverage errors, prior-wave inconsistencies, range checks based on instrument skip patterns, and reproducible join assertions. Never treat observational mismatch counts as causal outcomes.
