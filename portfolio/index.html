How to assess this work

Each project contains a working task or computation, a transparent data-generating process, an explanation of what the numbers mean, and methodological limitations. Code tests cover Bayesian updating, deterministic simulations, tax calculations, record-audit flags, ROI identities and reference-answer completeness.

Read documentation and limitations · Inspect test suite

Public deployment of a prototype does not establish research validity or professional accreditation. For serious evaluation, replication with independent data and external expert review is required.
